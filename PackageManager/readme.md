<h1 align="center">PackageManager</h1>

<p align="center">More possibilities for your site. One place to manage them.</p>

Bring your AWT plugins and themes together in a dashboard that puts you in control. PackageManager helps you find what’s installed, review new additions and manage the tools your site relies on—all from one familiar workspace.

## Your packages, clearly organised

Spend less time searching and more time improving your site. Browse your installed packages at a glance, search by name, description, author or version, and filter by package type to find exactly what you need.

Open any package to explore its details, see what it needs to work and read its documentation or license when available.

## Review first. Install with confidence.

Adding a package starts with a clear review. Choose a ZIP from a publisher you trust, check the package details and see whether anything else is needed before you confirm installation.

When required packages are missing, PackageManager can prepare them from the sources supplied by the publisher. You can review those sources and resolve compatibility issues before continuing.

New packages start disabled, so you decide when they become part of your site.

## Stay in control as your site grows

Enable the tools you need, disable those you’re no longer using and remove packages when it’s time to move on. Built-in checks help prevent changes that would affect other packages, while essential system packages remain protected.

## Keep every change in view

See who performed a package action, when it happened and how it turned out. The activity log gives administrators a shared history to refer to, while the dashboard’s recent-activity widget keeps the latest changes close at hand.

## Designed to feel at home

PackageManager fits naturally into the AWT dashboard, with light and dark themes, layouts that adapt to your screen and built-in help for everyday tasks.

| What you need | How PackageManager helps |
| --- | --- |
| A clear overview | Searchable package cards and filters for plugins and themes |
| An informed choice | Package details, documentation and licenses in one place |
| A guided installation | Review your ZIP and required packages before confirming |
| Everyday control | Enable, disable and remove packages with dependency checks |
| Shared visibility | Activity history and a recent-activity dashboard widget |

## Start with your next package

PackageManager is built for administrators using **AWT 27 or later**, with **Dashboard** and **URPC** installed.

Once PackageManager is set up, open **Dashboard → Packages** to explore your installed tools. To add something new:

1. Choose **Install from disk** and select a trusted package ZIP.
2. Review the package and prepare any missing requirements from trusted sources, where available.
3. Confirm installation, then enable the required packages and your new addition when you’re ready.

Package discovery through the **Browse** page is coming soon. You can already install packages downloaded from publishers you trust.
